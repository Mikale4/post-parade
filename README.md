# Umamusume: Post Parade

An unofficial Umamusume: Pretty Derby fan game: a racing game you prepare for rather than
play. Pick a racer, build her deck, train her through a career, and walk the academy as a
voxel trainer. During a race your only lever is the **Callout**; the racers run on the
real game's stats and signature skills and play their own cards by temperament.

**Play:** https://mikale4.github.io/post-parade/ (computer or phone). Accounts and saves
live in your browser, so each device keeps its own.

Or locally: double-click **`Play Post Parade.bat`**. It serves this folder over a small
local web server (Python 3 must be installed) and opens the game. Opening
`race/index.html` straight off the disk does not work: the browser blocks it from loading
the art and music next to it.

## What's here

| Folder | What it is |
|---|---|
| `race/` | The game: every script, page and stylesheet. Its `README.md` documents how it all works. |
| `Racers/` | Racer portraits and art, only the files the game loads. |
| `backgrounds/` | Scene backgrounds, only the files the game loads. |
| `audio/` | The game's music (from the gamerip) and two CC0 crowd recordings in `audio/sfx/`. |
